## Reportar um problema ou vulnerabilidade de segurança

A equipe do microsandbox recebe relatórios de segurança com bons olhos e se compromete a dar atenção rápida a questões de segurança. Esses assuntos devem ser reportados de forma **privada** por [security@superrad.company][support-email]. **Não** abra issues públicas no GitHub para isso.

## Avisos de segurança

A equipe do projeto se compromete com transparência no processo de divulgação de problemas de segurança. O time do microsandbox publica avisos de segurança pelo [portal de segurança][sec-advisories] do repositório no GitHub e pela [base de avisos RustSec][rustsec-db].

[rustsec-db]: https://github.com/RustSec/advisory-db
[sec-advisories]: https://github.com/microsandbox/microsandbox/security/advisories
[support-email]: mailto:security@superrad.company
